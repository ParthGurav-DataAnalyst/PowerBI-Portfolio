# Financial Performance (Profit & Loss) Dashboard

## Overview

Developed a comprehensive Profit & Loss analytics dashboard in Power BI to monitor financial performance across multiple business units. The dashboard provides visibility into revenue, costs, profitability, and operating performance through interactive reporting and KPI tracking.

## Dashboard Objectives

- Monitor overall financial health
- Analyze profitability across business units
- Track revenue and expense trends
- Evaluate gross profit performance
- Support management reporting and decision-making
- Compare financial performance across reporting periods

## Key Features

### Executive KPI Summary

The dashboard provides a high-level overview of:

- Total Income
- Total Expense
- Gross Profit
- Gross Profit Percentage

### Profit & Loss Analysis

Detailed P&L breakdown including:

- Total Sales
- Cost of Goods Sold (COGS)
- Gross Profit
- Indirect Expenses
- EBITDA

### Company-Wise Performance Analysis

Enables comparison of financial performance across multiple business units and locations.

### Fiscal Year Analysis

Interactive fiscal year selection allows users to evaluate financial performance across different reporting periods.

### Monthly Financial Summary

Tracks monthly trends for:

- Revenue
- COGS
- Gross Profit
- Indirect Expenses
- EBITDA
