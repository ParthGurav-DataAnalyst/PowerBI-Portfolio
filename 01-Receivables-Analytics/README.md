# Receivables Analytics Dashboard

## Business Overview

Designed and developed an Accounts Receivable (AR) analytics solution to provide complete visibility into customer outstanding balances, overdue invoices, and collection performance.

## Key Business Objectives

- Monitor customer receivables in real time
- Track overdue invoices through aging analysis
- Improve collection efficiency
- Identify high-risk outstanding accounts
- Support finance teams with actionable insights

## Key Features

- Customer-wise Outstanding Analysis
- Aging Buckets (0-30, 31-45, 46-60, 61-90, 90-120, >120 Days)
- Current Month Billing & Collection Tracking
- Invoice-Level Drill Down
- Dynamic Customer Search
- Executive KPI Monitoring

## Tools & Technologies

- Power BI
- DAX
- Power Query
- Excel
- Data Modeling

## Skills Demonstrated

- Financial Analytics
- KPI Design
- DAX Calculations
- Data Transformation
- Interactive Reporting

## Data Security

All customer names, invoice information, and sensitive business data have been anonymized.
