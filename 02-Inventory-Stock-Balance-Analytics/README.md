# Inventory & Stock Balance Analytics Dashboard

## Overview

Developed an inventory management dashboard to provide warehouse-wise visibility into stock quantities, inventory valuation, and product availability across multiple locations. This solution enables inventory and operations teams to efficiently monitor stock levels, analyze inventory value, and support data-driven supply chain decisions.

## Key Features

- Warehouse-Wise Inventory Tracking
- Item-Level Stock Monitoring
- Inventory Valuation Analysis
- Quantity and Value Reporting
- Search by Item Code and Item Name
- Brand-Wise Inventory Analysis
- Dynamic Filtering and Analysis
- Inventory Summary Reporting

## Dashboard Components

### Dashboard 1 – Stock Balance Dashboard

Provides warehouse-wise inventory visibility, stock quantity monitoring, inventory valuation, and item-level stock analysis.

### Dashboard 2 – Item Summary Dashboard

Provides product-level sales trends, inventory balances, brand-wise analysis, and quantity movement tracking across multiple years.

## Data Security

All product names, item codes, warehouse names, brand names, and business-sensitive information have been anonymized for portfolio purposes while preserving the analytical structure and business logic of the solution.
